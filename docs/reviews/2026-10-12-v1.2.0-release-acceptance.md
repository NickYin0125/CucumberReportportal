## Packaging And Scope

- Cucumber is constrained to `>=9,<11`; cucumber-expressions is constrained to `>=17,<19`. The latter avoids the observed native Cucumber 10 message-builder incompatibility, including parameterized steps.
- The gem includes English onboarding, CHANGELOG, runtime/CLI and the independent API/Playwright example; repository specs, root Feature scaffolding and unpublished duration/chaos experiments are excluded from the gem.
- Release source excludes the unvalidated duration feature files and profile/task. Their original working-copy content is retained, not removed or silently published.
- The default Cucumber fixture now returns a documented per-log `id` acknowledgement and asserts a complete receipt. A historical `message: ok` stub was correctly treated as a rejected log; merely passing the old call-sequence assertion was not delivery acceptance.
- The companion chart stays **1.2.0-rc.2**, pins official chart 26.8.12 / ReportPortal 26.0.5, and is not promoted to production GA. Its explicitly excluded legacy public bucket policy still permits anonymous write/delete; disabling initialization does not revoke an existing policy. Use the documented production restrictions.
- Publication is a GitHub Release with downloadable artifacts and checksums. RubyGems.org publication requires separate credentials and is not implied.

## Retained Environment Attempts

The first copied-example invocation selected macOS Ruby 2.6 and was correctly rejected by the Ruby >=3.1 guard. The corrected Ruby 3.4.2 installation succeeded. A first Playwright attempt lacked Node on its subprocess PATH; its incomplete evidence was retained, the owned process was stopped, and a fresh run with the existing Node/Chromium installation passed. A first root Cucumber control had reporting explicitly disabled in its invocation, so it produced no expected HTTP calls; the standard clean-source invocation was rerun without that override. No unsuccessful attempt is included as a passing gate above.

Acceptance is local Ruby 3.4.2 / macOS with Cucumber 9 and 10, Playwright Ruby 1.62.0 / CLI 1.62.1 and ReportPortal 26.0.5. It does not certify Cucumber 11, a complete Ruby/OS matrix, long-duration load, production HA, exactly-once delivery, anonymous media-policy security or historical database migration.
