## Publication Gates

Previous GitHub CI failed before tests because its fresh runner had not registered
the upstream Helm repository. Shared validation now registers that repository,
builds the locked dependency, checks deployment profiles and runs offline tests.
Tag publication reuses that validation and verifies stable tag/version agreement
and main-branch ancestry before publishing verified assets and checksums.

The PR, main and tag runs must finish successfully before publication is called
complete. GitHub Release publication is not RubyGems/private-registry publication.
No Huawei production deployment, HA certification, historical migration,
exactly-once delivery or zero-loss guarantee is included.
