## Publication Boundary

The stable tag must be on main and match both SDK/Chart versions. The GitHub tag
workflow reruns validation before publishing Gem, Helm archive, release manifest
and SHA256SUMS. Consult its run and the immutable release manifest for the final
publication commit and artifact digests; this local record does not invent a CI
completion state before it happens. RubyGems.org publication is separate.

Archived MinIO images still require production approval/mirroring. No historical
data migration, Huawei deployment, HA certification, new 15-minute endurance run
or full Ruby/Cucumber version matrix is claimed by this release check.
