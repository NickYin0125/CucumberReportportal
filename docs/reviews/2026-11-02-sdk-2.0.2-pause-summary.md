## Security Finding And Test Integrity

The deferred probe uses only synthetic values, not real credentials. Its malformed frame is structurally `https://example.test/bad path#<encoded JSON credential>`, followed by 62 safe frames. Direct whole-URL sanitization masks the value, but text tokenization stops at the space and leaves the encoded fragment outside that route.

Both fresh and shared-policy results are identical, including the leak. An independent offline execution against immutable `50b6d4d`, with networking disabled and no RP credentials, exited **1**. No probe traffic was sent to RP; no real credential exposure is claimed.

During test development the original failing fixture was replaced before the stop instruction arrived. That replacement's passing results did **not** clear the original failure. The original input and failure log were preserved, and the exact input was restored as a separate executable probe that still exits nonzero. It is not a pending-test waiver or part of the passing unit count.

Owner decisions remain:

- Authorize a separate performance-only optimization and revalidation, without weakening redaction or changing raw evidence.
- Do not expand this round to fix the malformed-URL issue; retain it as a release blocker.
- Pause further work and commit this summary.
